A small Python desktop app for checking PS3 video compatibility and converting unsupported files into a PS3-friendly format.

PS3MediaChecker is a simple Python app made to help sort out video files for PS3 use. It lets you select a file or scan a whole folder, checks the video and audio format, and tells you what should work on a PS3. If a file is not supported, the app can also convert it to a more PS3-friendly MP4 format using FFmpeg.
